# Navisworks version support

Navisworks Manage 2024 là runtime-certified reference của kit. Các profile 2020–2023 và 2025–2026 chỉ được ghi build/profile cho tới khi học viên test trực tiếp đúng version/edition.

Mỗi bài cuối khóa phải có bảng: version, edition, build pass, runtime test pass, feature đã test và giới hạn. Simulate không được ghi là hỗ trợ Clash.
