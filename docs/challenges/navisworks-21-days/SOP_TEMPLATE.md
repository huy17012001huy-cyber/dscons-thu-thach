# SOP một ngày — Navisworks

1. Mở model mẫu/bản sao và đọc capability matrix.
2. Copy prompt của ngày vào AI Agent; yêu cầu AI nói rõ feature đã được runtime test hay chưa.
3. Xác nhận kế hoạch và giới hạn trước khi để AI sửa code hoặc tạo report.
4. Chạy đúng edition/version, lưu output riêng và đối chiếu với Model Tree/Properties/Selection Tree.
5. Chụp ảnh kết quả. Nếu có sản phẩm/report, đăng ảnh lên Bảng tin.

```text
Mục tiêu hôm nay: [một output cụ thể].
Navisworks version/edition: [ghi rõ]. Kit: [KIT_ROOT].
Hãy đọc workspace và capability matrix, lập kế hoạch, liệt kê file sẽ đổi
và chờ tôi xác nhận. Không xóa file, không sửa NWF/NWD gốc, không dùng
Simulate cho Clash, không tạo nút giả cho capability chưa được test.
Sau khi làm xong hãy báo file đã đổi, runtime evidence, kết quả và giới hạn.
```
