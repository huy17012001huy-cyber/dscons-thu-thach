# SOP một ngày — AutoCAD

1. Mở đúng Kit và DWG bản sao.
2. Copy prompt của ngày vào AI Agent; yêu cầu AI đọc file và lập kế hoạch trước.
3. Xác nhận file được sửa, build profile và cách rollback.
4. Để AI thực hiện; build/chạy đúng AutoCAD version.
5. Chụp ảnh command/plugin/output trong AutoCAD. Nếu có sản phẩm, đăng ảnh lên Bảng tin.

```text
Mục tiêu hôm nay: [một output cụ thể].
Ứng dụng/version: [AutoCAD version/edition].
Kit: [KIT_ROOT]. Workspace: [đường dẫn].
Hãy đọc file trước, lập kế hoạch và chờ tôi xác nhận.
Không xóa file, không sửa DWG gốc, không đổi cấu hình bảo mật,
không đoán API. Sau khi làm xong hãy báo file đã đổi, lệnh build,
cách chạy, kết quả và giới hạn.
```
