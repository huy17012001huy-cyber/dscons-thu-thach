# AutoCAD version support

Kit có profile AutoCAD 2019–2026. Mỗi học viên phải ghi version/edition thật, target framework, build status và runtime test status.

Không gọi một version là “đã hỗ trợ” chỉ vì build thành công. Bản reference dùng quay mẫu nên được ghi riêng; artifact runtime-tested và build-only phải tách rõ trong support matrix.
