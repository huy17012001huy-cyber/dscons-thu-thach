# Mapping UI Challenge

| Nguồn crawl | DSCons |
|---|---|
| Danh sách ngày dạng accordion | Giữ accordion, thêm số ngày, hình thức, XP và trạng thái thật |
| Header task có chip | Dùng chip xanh DSCons/cam, không dùng xanh lá Focus |
| Progress challenge | Hiển thị số bài đã duyệt trên tổng số bài |
| Guide dài dạng trang riêng | `/c/{community}/challenge/{slug}/ngay/{day}`; Revit dùng ngày 7, 12, 15, 18, 20, 21 |
| Note block | Thông tin, cảnh báo, thành công, gợi ý và lỗi thường gặp |
| Panel điều hướng | Nút quay lại challenge và ngày trước/sau |

SOP luôn một cột; nội dung dài được chia thành các khối dễ quét và không lộ khi task chưa mở.
